# qdrop air

Лёгкое веб-приложение для мгновенной передачи файлов (до 300 МБ), скриншотов (`Ctrl+V`) и короткого текста/ссылок между учебным ПК и смартфоном по 6-значному коду или QR.

Весь трафик идёт по `HTTPS :443` через **Yandex Cloud (Cloud Function + приватный Object Storage)** — работает в РФ на любых мобильных и учебных сетях без WebRTC, Metered и Cloudflare.

## Безопасность и приватность

- **Изоляция бакетов**: сервисный аккаунт `qdrop-air` не имеет ролей на каталог — доступ ограничен Bucket Policy к одному бакету и префиксу `rooms/*`, плюс жёсткий лимит размера бакета **1 ГБ**.
- **Строго 1-на-1**: участники комнаты получают криптографические токены (в бакете хранятся только `SHA-256` хеши); сторонние попытки входа отклоняются (`409`).
- **Автоудаление**: при нажатии «Отключиться» или закрытии вкладки все файлы комнаты удаляются сразу; дополнительно действует Lifecycle-правило бакета (очистка `rooms/*` через 1 день).
- **Подпись `Content-Length`**: одноразовые ссылки `PUT` жёстко привязаны к размеру файла.
- **Без следов на учебном ПК**: `localStorage` не используется; временные настройки живут только в `sessionStorage` текущей вкладки.

## Локальный запуск

```zsh
python3 -m http.server 8000 --directory /home/qualbyy/Проекты/qdrop-air
```

Открой `http://localhost:8000` в двух вкладках (для локальной отладки у функции должна быть переменная `ALLOW_LOCALHOST=true`).

## Публикация на GitHub Pages

1. Укажи URL развёрнутой функции Yandex Cloud в `relayUrl` в [config.js](config.js).
2. Выложи в корень репозитория `index.html`, `style.css`, `app.js`, `config.js`, `qrcode.min.js`, `html5-qrcode.min.js`.
3. Включи **Settings → Pages → Deploy from a branch** (`main` / `/(root)`).
